Ringkasan

SmartStitch Web adalah implementasi server-side untuk aplikasi desktop Windows SmartStitch karya MechTechnology. Perilaku pemrosesan direkonstruksi dari artefak SmartStitch.exe (PyInstaller, PySide6, Python 3.10) dan diselaraskan dengan dokumentasi sumber terbuka proyek.

Pipeline Pemrosesan

  1. Memuat seluruh berkas gambar dan mengurutkannya secara natural.
  2. Menyesuaikan lebar sesuai mode Width Enforcement.
  3. Menggabungkan gambar menjadi satu kanvas vertikal atau horizontal.
  4. Menentukan titik potong melalui Direct Slicing atau Smart Pixel Comparison sesuai arah gabungan.
  5. Mengekspor setiap segmen ke format yang dipilih dengan tingkat kualitas tertentu.

Keselarasan Implementasi

Mode otomatis menggunakan lebar terkecil, tinggi hasil resize dibulatkan ke bawah, kanvas gabungan berlatar hitam, batas segmen akhir adalah height-1, dan detektor pintar membandingkan piksel horizontal pada baris yang berdekatan. Penamaan berkas mengikuti format dua digit (01.ext, 02.ext).

Privasi & Kompatibilitas

Gambar diproses di server dengan Node.js, Sharp, dan ag-psd. Input, kanvas gabungan, dan output disimpan sementara di bucket R2 lalu dihapus setelah arsip ZIP selesai dibuat. Format input/output yang didukung: PNG, JPG, JFIF, WEBP, BMP, TIFF, TGA, PSD, dan PSB. Profil konfigurasi disimpan di localStorage dengan schema field yang sama dengan settings.json pada versi desktop.

Tampilan antarmuka menggunakan pendekatan SaaS modern dan tidak mereplika stylesheet aplikasi desktop.
